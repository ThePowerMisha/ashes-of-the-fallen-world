# Классы alpha
Команды без OP: `/trigger ashes_class set 1` (1–6), `/trigger ashes_status`, `/trigger ashes_purify`. После входа подождите до одной секунды. Смена класса раз в 600 секунд онлайн. Ранги 1–3; прогресс по статистике с момента установки пакета, а не с момента выбора. Выбор не ограничивает использование модов. Атрибуты добавляются отдельными UUID, не меняют базовые значения. После смерти переустанавливаются.

| № | Класс | Статистика | Ранг 2 / 3 | Бонус за ранг |
|---|---|---|---|---|
| 1 | Паладин | Убийства мобов | 50 / 200 | +1 броня |
| 2 | Архимаг | Зачарования | 10 / 30 | +2 здоровья |
| 3 | Инженер | Добытый обычный камень | 500 / 2000 | +0.1 скорость атаки |
| 4 | Следопыт | Пройдено пешком | 1 / 5 км | +0.008 скорость движения |
| 5 | Архитектор | Использования каменных кирпичей | 100 / 400 | +0.04 сопротивление отбрасыванию |
| 6 | Оккультист | Убийства мобов | 50 / 200 | +0.5 урон |

Это временные ванильные атрибуты, не интеграция с маной, добычей или магическими навыками. Основной класс остаётся независимым от визуального дерева мастерства; отдельные пассивные бонусы дерева описаны в SKILLS.md.

## 0.9: активные таланты
`/trigger ashes_talent set 1` на II ранге, `... set 2` на III ранге; `/trigger ashes_ability` применяет выбранное умение (90 секунд перезарядки). Выбирается один талант, переключение доступно по рангу. При смене класса талант сбрасывается.

| Класс | Талант 1 | Талант 2 |
|---|---|---|
| Паладин | Сопротивление 12 с | Поглощение II 20 с |
| Архимаг | Регенерация 10 с | Огнестойкость 30 с |
| Инженер | Спешка II 25 с | Сопротивление 20 с |
| Следопыт | Скорость II 20 с | Ночное зрение 45 с |
| Архитектор | Спешка 20 с | Регенерация 12 с |
| Оккультист | Сила 12 с | Сопротивление 16 с |

`/trigger ashes_cleanse` с зарядом на ванильном скалке даёт очищенный образец (60 секунд); блоки не меняются. Для земель используется штатный очиститель. Визуальное дерево и меню добавлены в RC2 — см. SKILLS.md.
