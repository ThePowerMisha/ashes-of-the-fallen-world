# Рубежи поселений

Магнетит + один `kubejs:ward_charm`: встань на магнетит в Overworld, введи `/trigger ashes_ward set 1` или выбери пункт в `/trigger ashes_menu`. Проверка радиуса: `/trigger ashes_ward set 2`. Установка регистрирует настоящее достижение для главы 34. Для удаления достаточно сломать магнетит; маркер удалится в загруженном чанке. Не создаёт блоки, не изменяет приваты, не удерживает чанки. Устанавливать только с разрешения владельца участка; станция общая, без индивидуального владения. Минимальное расстояние до другой загруженной станции — 32 блока; максимум 64 загруженных станций.

- При наличии игрока в 48 блоках и орды в 32 блоках: сигнал тревоги не чаще раза в 30 секунд; в радиусе 24 блоков — Сопротивление I для игроков, деревенских жителей и зарегистрированного типа MineColonies `citizen`, Слабость I и Замедление I для перечисленных бойцов орды. Эффекты длительностью 3 секунды обновляются каждую секунду, пока есть угроза. Не действует на курсоры, снаряды, других модовых существ и боссов вне списка.
- **Не барьер от заражения.** Замкнутый контур из штатного Infestation Ward Block Sculk Horde, защита входов и подземных путей, штатный очиститель, стены и приваты FTB Chunks остаются необходимыми. Не гарантируется полная неприкосновенность построек; не включаются экспериментальные механики Sculk Horde.
- Проверка перед релизом: активация без OP, отказ без предмета, расход одного предмета, повторная активация и соседняя станция, перемещение между измерениями, перезапуск, удаление магнетита, сигнал при появлении орды, эффект на жителях и отсутствие сигналов без угрозы.
