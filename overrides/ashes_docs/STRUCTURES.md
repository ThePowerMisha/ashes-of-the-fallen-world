# Места памяти — авторские структуры
Шесть типов, по два варианта архитектуры (светлый камень/ель и тёмный глубинный сланец/тёмный дуб). 12 настоящих сжатых NBT-шаблонов Minecraft 1.20.1, DataVersion 3465, без сторонних модовых блоков. Размеры и число блоковых записей: docs/lore-structures.json. Генератор tools/structures.py сохраняет детерминированные шаблоны и JSON; в существующие чанки ничего не вставляет.

## Генерация
Единый random_spread structure_set (spacing 40 чанков, separation 18, разные веса), максимум один старт на регион этой сетки; не гарантирует отсутствие пересечений с чужими структурами. Отдельные теги низин, лесов и высокогорий, только подходящие ванильные биомы и необязательные ID Terralith. Ригидные jigsaw-пулы с двумя вариантами, depth 0, привязка WORLD_SURFACE_WG, beard_thin и двухслойные основания. Никакого глобального изменения шумов. На крутых склонах возможны недочёты адаптации. Живые поселения MineColonies и ванильные деревни не заменяются. Руины не содержат автоматических спавнеров и не запускают орду.

## Добыча и открытия
Каждый сундук имеет собственную loot table с оригинальной русской письменной книгой (текст истории), одним уже существующим предметом Ashes и небольшими припасами. Не выдаются печати финала или мощное снаряжение. Дневники не являются уникальными в масштабе мира; один тип истории может встретиться повторно. Реальная работа Lootr на этих сундуках ещё не проверена. Первое посещение каждой структуры подтверждается advancement minecraft:location с predicate.location.structure, по образцу vanilla 1.20.1; выводится персональное сообщение хроник, учитывающее mute. Не требует OP.

## Проверка
Новый тестовый мир с KubeJS; проверить /datapack list, /locate structure ashes:silent_hamlet (и другие ID), затем посетить сооружения, проверить сундуки/книги, достижение, чат и перезапуск. /place template ashes:lore/silent_hamlet_1 подходит для осмотра геометрии на тестовом мире, но не создаёт зарегистрированный старт структуры и не подтверждает достижение посещения. Проверять разные сиды и пересечения с YUNG/When Dungeons Arise. Шаблоны прочитаны независимым локальным NBT-декодером, координаты и индексы палитры валидны. Minecraft не запускался.
