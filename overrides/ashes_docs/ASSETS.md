# Визуальные ассеты Ashes

30 предметов KubeJS имеют собственные текстуры. Все десять сгенерированных изображений использованы как исходники: восемь отдельных артефактов и две таблицы спрайтов. Концепты сопоставлены с существующими ID; лишние ячейки таблиц не создают новых предметов. Досье трёх орденов имеют различные цвета и символы.

- Путь: `overrides/kubejs/assets/kubejs/textures/item/<id>.png`.
- Обычные предметы: 32×32, ключевые артефакты: 64×64, прозрачный фон.
- `tools/build.py` генерирует привязку `kubejs:item/<id>`; сами текстуры являются исходными бинарными ассетами и не перегенерируются.
- Игровые ID, рецепты и квесты не меняются. Проверка визуала в Minecraft ещё не выполнена.

## Анимированные артефакты

| ID | Предмет |
|---|---|
| `ward_charm` | Оберег рубежа |
| `renewal_heart` | Сердце возрождения |
| `nature_seal` | Печать хранителей |
| `concord_core` | Ядро согласия |
| `abyssal_seal` | Печать бездны |
| `purifier_matrix` | Матрица очищения |
| `cleansing_charge` | Заряд очищения |
| `final_testament` | Завещание трёх орденов |

Восемь кадров 64×64 на артефакт, вертикальная лента 64×512, интервал 3 тика, интерполяция. Световые акценты пульсируют, корпус остаётся неподвижным; это анимации текстур, не динамические 3D-модели или фактическое освещение окружающего мира. Не требует новых модов. 22 остальные текстуры статичны.
