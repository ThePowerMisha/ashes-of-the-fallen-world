# 0.9.0-rc1 — статус выпуска

Целевой функционально расширенный кандидат на выпуск, не подтверждённый запуском Minecraft. 129 проектов CurseForge (включая Complementary Unbound), 423 квеста / 33 главы, 30 предметов, 32 рецепта. 258 заданий на предметы, 6 на достижения Sculk Horde, 159 с явно обозначенным ручным подтверждением. 6 классов, 3 ранга, 12 альтернативных активных талантов. Старые 101 ID квестов сохранены.

## Реализовано
- Основной сюжет, архивные свидетельства, 21 дополнительная глава обучения. LootJS добавляет досье и осколки к ванильным таблицам сундуков; дополнительно их можно получить рецептами.
- Класс и ранги по индивидуальной статистике; талант через trigger, не требует OP. Классы не ограничивают доступ к модам. Знак очищения снимает отрицательные эффекты; сбор образца тратит заряд и не меняет мир. Землю очищает штатный Sculk Horde.
- Клиентские options.txt и Oculus-профиль, встроенный шейдер по ссылке манифеста, серверный шаблон, Sculk Horde defaultconfig, одноразовые gamerules. Almost Unified и Polymorph применяются со штатными настройками.
- Все первоначально включённые проекты сохранены; 16 новых, Waystones обновлён. Distant Horizons не в основном пакете: сочетание с Oculus требует отдельной проверки. Sound Filters не дублируем.

## Не подтверждено / не реализовано
- Игра и выделенный сервер не запускались. Статическая проверка не проверяет API модов, загрузку JAR, реестр предметов, реальное выполнение квестов, производительность и баланс прохождения. Манифест проверен по доступным метаданным, не по всем JAR.
- Нет собственного визуального дерева Pufferfish: вместо него реализованы команды, 3 ранга и 2 альтернативы таланта для каждого класса. Нет технического ограничения пробуждения орды главой, паузы на пустом сервере или защиты от заражения внутри приватов. Штатные средства Sculk Horde; пробуждать по договорённости.
- Не все моды имеют индивидуальные конфиги: неизменённые параметры остаются штатными. Некоторые квесты на действия и боссов — ручные; финал требует достижения поражения орды. Не заявлять полную совместимость или завершённость до прохождения.
