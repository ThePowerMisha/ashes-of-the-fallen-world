# Классы, таланты и дерево мастерства

Открой меню командой `/trigger ashes_menu` или ПКМ с Печатью экспедиции. На странице класса отображаются его роль, способ увеличения ранга, активные таланты и требуемые ранги. В меню есть отдельные кнопки применения навыка и открытия дерева. Подробности в [справке по авторскому контенту](AUTHOR_CONTENT.md).

В категории `ashes:mastery` 54 узла. За каждый достигнутый ранг выдаётся три очка, максимум девять. Можно сочетать пассивные пути разных классов. Каждый из шести классов предлагает четыре активных таланта, из которых одновременно выбран один. Класс и таланты сохраняются по игрокам.

`tools/skills.py` генерирует дерево и страницы классов, `tools/gameplay.py` — активные эффекты. Сохраняй старые ID узлов и слоты активных талантов при изменениях.
