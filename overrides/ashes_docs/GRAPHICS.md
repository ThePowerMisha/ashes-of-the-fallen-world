# Графические настройки RC3

Основной профиль: Oculus 1.8.0, Embeddium 0.3.31, Distant Horizons 3.1.2-b, Dynamic Lights, Extras и Options API. Конфигурации адаптированы по предоставленному Once upon an year.zip: 128 вместо 256 LOD-чанков, 4 вместо 10 потоков, ограничение запросов генерации 4/с, динамический свет FAST вместо REALTIME, дополнительные distance culling отключены во избежание двойного отсечения. Обычная дистанция 12, симуляция 6. Первый запуск без шейдеров; затем Complementary Unbound. Также доступны Reimagined, Bliss, Solas и BSL. При артефактах с DH/Oculus использовать отдельный профиль Horizons, либо отключить DH в основном. Совместимость конкретного рендера не доказана запуском. LOD-сервер опционален, нагрузку и совместимость генерации проверить. Не копируем serverId и прочие идентификаторы старого мира.

ParCool: клиентский профиль с умеренными скоростями и отключением резких поворотов камеры. Это клиентские настройки, а не серверный запрет действий. JEI Integration показывает характеристики по Shift.
