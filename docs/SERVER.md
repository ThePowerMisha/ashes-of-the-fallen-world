# Сервер и правила
- Java 17, Forge из manifest.json, одинаковые обязательные моды на сервере и клиентах. На сервере уберите только точно клиентские моды после проверки их зависимостей; список кандидатов в overrides/ashes_docs/CLIENT_ONLY.txt. Не копируйте клиентский options.txt на сервер.
- Перенесите config, defaultconfigs (если имеются) и kubejs из профиля в корень сервера. Создайте новый тестовый мир. Не включайте offline-mode и не отключайте проверку подлинности.
- Примените server.properties.example как шаблон (не перезаписывайте действующие настройки без резервной копии). Рекомендуются PvP off, normal, view-distance 8, simulation-distance 6, белый список.
- 10–16 ГБ для выделенного сервера на 4–6 человек — ориентир, а не гарантия.
- Сделайте одну команду FTB Teams для общего сюжета. Проверяйте разделение наград и доступов. Используйте FTB Chunks и согласованные правила доступа.
- Sculk Horde: после первого запуска найдите сгенерированный конфиг мода. В ветке 1.20 исходника ModConfig.java предусмотрены trigger_ancient_node_automatically (false), disable_defeating_sculk_horde (false), infection_speed_multiplier, purification_speed_multiplier и sculk_raid_global_cooldown_between_raids_minutes. Проверьте точные имена и расположение в установленной версии. Для среднего режима начните с автоматического пробуждения false, скорости заражения 0.5 и очищения 1.5; после пробного мира настройте. Не отключайте загрузку чанков вслепую: это ломает часть штатных механик орды. Обелиски поддерживают жителей и игроков; штатные барьеры защищают от распространения. Пауза орды без игроков настроена; проверить работу.
- Пробуждение только после согласия участников и резервной копии. Квест не блокирует штатную активацию технически. Остановленный сервер не симулирует мир; для паузы пустого сервера потребуется отдельная настройка хоста или мод.
- Не обновляйте версии автоматически. Перед каждым обновлением копируйте мир, config и данные FTB Quests.

## 0.9
Параметры нового мира внесены в config/sculkhorde_config.toml: автопробуждение false, скорость заражения 0.5, очищения 1.5, радиус 48, рейды 360 минут. Проверьте фактически загруженный конфиг: исходник мода и выбранный JAR могут отличаться. Ритуал образца больше не меняет блоки.

## Настройки мира
См. [MOD_CONFIGS.md](MOD_CONFIGS.md) и [WARDS.md](WARDS.md). Скопировать `config/` и `defaultconfigs/` до создания мира; не переносить старые serverconfig поверх новых без сравнения. Для старого мира сохранить резервную копию и применить изменённые FTB-параметры вручную.

## RC3
Шейдеры и клиентские графические аддоны серверу не нужны. ParCool и игровые моды должны совпадать на обеих сторонах. Для новых шумов и жил рекомендуется новый мир; retrogen выключен. Хроники настраиваются каждым игроком `/trigger ashes_news set 2` (выкл.) / `set 1` (вкл.).

## Предгенерация чанков

Chunky 1.3.146 включён в оба профиля. С правами оператора выберите нужное измерение через `/chunky world`, задайте центр и радиус командами `/chunky center` и `/chunky radius`, затем выполните `/chunky start`. Ход выполнения показывает `/chunky progress`. В серверной консоли команды вводятся без начального слеша.
