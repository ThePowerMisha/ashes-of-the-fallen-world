# Настройки модов для кооператива

Файлы распространяются вместе со сборкой. Не перезаписывать существующий мир без резервной копии; FTB defaultconfigs применяются при создании серверного конфига мира. Для уже созданного мира нужно перенести настройки выборочно и проверить их через интерфейс модов.

| Мод | Параметры |
|---|---|
| Sculk Horde | `config/sculkhorde_config.toml`: правильное расположение согласно исходникам 1.20; NORMAL, пауза при пустом сервере, без автопробуждения, распространение ×0,5, очищение ×1,5, радиус 48, рейд не чаще 6 часов, повторная атака зоны не раньше 12 часов, ограничение 160 бойцов и 1 узел, радиус загрузки 6 чанков, автонастройка производительности. AMD compatibility mode без свечения мобов. |
| FTB Chunks | `defaultconfigs/ftbchunks/ftbchunks-world.snbt`: 256 приватов и 8 force-loaded чанков на базовый лимит, потолок команды 512/16, офлайн-загрузка запрещена, PvP и взрывы в привате отключены; автоматизация fake players разрешается владельцем отдельно и только для доверенной машины. |
| FTB Ultimine | `defaultconfigs/ftbultimine/ftbultimine-server.snbt`: максимум 48 блоков, обязательный инструмент, не ломать инструмент при последней единице прочности, останавливаться при запрете добычи, cooldown 10 тиков; голод штатный. |
| Pufferfish Skills | Дерево из 18 узлов в KubeJS data, максимум 3 очка. |
| FTB Quests | 431 квест, стабильные ID, задачи на достижения, крафт и действия. |
| Oculus | Шейдер выключен при первом старте; атмосферный профиль по выбору. |
| Остальные | Настройки штатные; баланс через рецепты, квесты и правила мира. Не заявляется ручное конфигурирование всех 129 проектов. |

Схемы сверены по исходникам [Sculk Horde](https://github.com/TeamPeril/Sculk-Horde/tree/1.20), [FTB Chunks](https://github.com/FTBTeam/FTB-Chunks/tree/1.20.1/main), [FTB Ultimine](https://github.com/FTBTeam/FTB-Ultimine/tree/1.20.1/main), [FTB Library](https://github.com/FTBTeam/FTB-Library/tree/1.20.1/main). Наличие параметров сверено с этими ветками; точные JAR и применение в игре ещё не проверены. В частности, проверить отсутствие игроков, перезапуск и наличие рабочих механизмов MineColonies/Create внутри приватов. Если NPC заблокированы, настройте права команды, не отключайте глобально защиту.
