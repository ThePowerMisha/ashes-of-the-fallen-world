# Хроники мира
Система работает раз в секунду в существующей функции ashes:second. Проверяет реальное состояние мира: смена погоды (дождь, гроза, ясное небо), рассвет, сумерки и полнолуние по обычному лунному циклу. При первой инициализации не выдаёт сообщения о текущей погоде и времени. Отдельно сообщает о первом получении достижений пробуждения и победы Sculk Horde, а игроку — о первом посещении Nether, End и Twilight Forest. Успех орды фиксируется один раз в общем мире, обнаруживается по достижениям онлайн-игроков; это не прямой API орды. События Enhanced Celestials не подменяются обычной луной; специфические кровавые луны не определяются этим скриптом. Погода и время выводятся игрокам Overworld. Персональное отключение /trigger ashes_news set 2, включение /trigger ashes_news set 1. Обычные предупреждения защитных обелисков не отключаются. Не изменяет время, погоду, состояние орды, не принуждает загрузку чанков. Состояние хранится в scoreboard и тегах, должно переживать рестарт. Реальный запуск ещё не проведён.

При первом входе в Верхний мир хроники сами сообщают время суток и погоду. Затем сообщения приходят при смене состояний. Личный выбор отключения сохраняется.
