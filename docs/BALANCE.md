# Баланс и настройки геймплея

| Механика | Реальная настройка |
|---|---|
| Ранний этап | Простые пайки и фонари, Ultimine и рюкзаки, Create как первый путь автоматизации. |
| Промышленность | Квесты Create → Mekanism/IE/IF, AE2 и энергетика; 32 дополнительных рецепта, в том числе связки Create/Mekanism/Ars/Botania. Базовые рецепты не удаляются. |
| Магия | Ars, Iron's Spells, Goety, Botania — отдельные линии с общим финалом. |
| Прогресс | Командная книга FTB Quests, индивидуальные scoreboard-классы; ручные задачи явно обозначены. |
| Ночь | 50% игроков для сна; звуковой фон, орда и дополнительные мобы. |
| Смерть | keepInventory=false, Corpse; PvP выключен в серверном шаблоне. |
| Поселения | doFireTick=false, mobGriefing=true для совместимости с NPC и ордой. FTB Chunks — права территории, не гарантия защиты от заражения. |
| Орда | Автопробуждение выключено; infection 0.5, purification 1.5, радиус 48, интервал рейдов 360 минут (config/sculkhorde_config.toml; пауза без игроков; проверить фактическое принятие). |
| Сундуки | Lootr и дополнения LootJS; 25–45% вероятность дополнительного документа в выбранных ванильных таблицах. |
| Таланты | Один из двух на ранге 2/3; перезарядка 90 секунд. Смена класса 600 секунд. |
| Мир | Большие горы и биомы; новый мир обязателен для новой генерации. Частоты структур и мобов оставлены штатными. |

Серверный шаблон, конфиг Sculk Horde и настройки FTB для нового мира описаны в [MOD_CONFIGS.md](MOD_CONFIGS.md). Одноразовая функция `ashes:world_defaults` применяет gamerules при загрузке datapack; администратор затем может изменить их вручную. Проверять реальный баланс в прохождении, не обещать заранее длительность или FPS.

RC3: укрупнены жилы без увеличения числа попыток vanilla placement; см. WORLDGEN.md. ParCool настроен клиентским профилем (не серверный запрет действий). Новые побочные главы не блокируют основной сюжет. Хроники не меняют состояние мира.
