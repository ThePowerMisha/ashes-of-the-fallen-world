# Пепел ушедшего мира — Ashes of the Fallen World
Версия 1.0.0-rc1. Minecraft 1.20.1, Forge 47.4.28, Java 17, 129 фиксированных проектов CurseForge. Кооператив 4–6 игроков, средняя сложность, мрачная атмосфера, большие горы и леса, развалины, поселения, технологии и магия. Русский язык квестов.

## Принятые решения
- Tectonic + Terralith; не добавлять ещё один глобальный генератор без теста.
- Create 6.0.8 и Steam 'n' Rails 1.7.2; Mekanism и дополнения одной версии. Embeddium + Oculus, без Distant Horizons в базовом профиле.
- FTB Quests: командная история; классы и прогресс индивидуальны (scoreboard). Lootr для личного лута. FTB Chunks для территорий.
- Sculk Horde — штатная система заражения и очистки земель. Собственный знак очищения лечит игрока, а не изменяет землю; пробуждение и поражение орды проверяются через достижения. Сбор образца не меняет мир.
- Цель 400–500 квестов по количеству достигнута: 431, включая 161 ручных. Проверка запуска не выполнена. Не называть сборку стабильной до тестов.
- Не менять версии модов без проверки зависимостей, не удалять моды из существующего мира без резервной копии.

## Лор
Механики, хранители природы и архимаги запустили общий источник энергии, разбудив живую силу в глубинах. После Раскола руины скрывают записи трёх орденов. Выжившие восстанавливают цивилизацию, соединяют магию и машины, очищают территорию и зажигают маяк новой эпохи.

- Визуальное дерево Pufferfish: 18 узлов, максимум 3 очка; обелиск защищает игроков и жителей в бою, штатный барьер нужен для земли. Профиль Horizons отдельно без Oculus/Complementary.
